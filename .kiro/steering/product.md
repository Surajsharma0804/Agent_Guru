# Agent Guru - Product Overview

Agent Guru is a world-class, always-on AI voice assistant designed to compete with and surpass Alexa, Siri, and Google Assistant. With dual personalities (Guru and Maya), it provides complete device control, adaptive intelligence, and privacy-first architecture.

## Mission: Best-in-Class Voice Assistant

**Goal**: Deliver the most intelligent, responsive, and capable voice assistant in the market with zero compromise on quality, performance, or user experience.

## Core Capabilities

- **Always-On Voice Control**: Sub-200ms wake word detection for "Hey Guru" or "Hey Maya" - faster than Alexa (250ms) and Siri (300ms)
- **Dual AI Personalities**:
  - Guru (professional, analytical, male voice) - for productivity and technical tasks
  - Maya (warm, creative, female voice) - for personal assistance and creative work
  - Seamless personality switching mid-conversation
- **Complete System Control**: Execute ANY operation through voice - beyond what Alexa/Siri can do
  - Applications, files, settings, messaging across ALL platforms
  - Advanced automation and scripting capabilities
  - Multi-step task execution with context awareness
- **Military-Grade Biometric Security**:
  - Multi-factor authentication (face + voice + fingerprint)
  - Liveness detection to prevent spoofing
  - Zero-knowledge proofs for sensitive operations
- **Adaptive Intelligence**:
  - Self-improvement engine with measurable 15% improvement after 100 tasks
  - Learns user preferences, habits, and communication style
  - Predictive assistance based on context and history
- **True Cross-Platform**: Windows, macOS, Linux, Android, iOS with feature parity

## Platform-Specific LLM Configuration

**Desktop (Windows/macOS/Linux)** - Maximum Flexibility:
- **Local Ollama**: FREE, private, offline, unlimited usage
- **Cloud API**: OpenAI GPT-4, Gemini Pro, Claude 3, DeepSeek (user's own API key)
- **Hybrid Mode**: Intelligent routing between local and cloud based on task complexity
- **Cost Optimization**: Automatic selection of cheapest provider for task requirements

**Mobile (Android/iOS)** - Optimized for Mobile:
- **Cloud API ONLY**: OpenAI, Gemini, DeepSeek, Anthropic (resource constraints)
- **User-Owned Keys**: Complete cost control and privacy
- **Secure Storage**: OS keychain integration (Keychain/KeyStore)
- **Budget Limits**: Set spending caps and usage alerts
- **Offline Fallback**: Basic commands work without internet

## Battery Optimization - Best in Class

**Desktop**:
- Sleep Mode: <3% CPU usage (wake word detection only)
- Wake Mode: <15% CPU usage (full processing with GPU offload)
- Intelligent GPU scheduling for maximum performance per watt

**Mobile**:
- **Sleep Mode**: <5% battery/hour (better than Siri's 7%, Alexa's 8%)
- **Wake Mode**: <10% battery/hour (better than Siri's 15%, Alexa's 18%)
- **Auto Transitions**: Sleep→Wake <100ms, Wake→Sleep after 30s inactivity
- **Adaptive Power**: Reduces processing based on battery level
- **Background Optimization**: Minimal impact on other apps
