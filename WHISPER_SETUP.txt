================================================================================
AGENT_GURU - WHISPER.CPP INTEGRATION GUIDE
Production-Grade Speech-to-Text Setup
================================================================================

OVERVIEW
--------
Agent Guru supports two STT modes:

1. PRODUCTION MODE (Whisper.cpp) - Real speech recognition
2. FALLBACK MODE (Audio Analysis) - Development/testing without Whisper

QUICK START
-----------
Run the automated setup script:

    setup_whisper.bat

This will:
- Download the Whisper base model (142 MB)
- Check for LLVM/Clang dependencies
- Build Agent Guru with Whisper support

MANUAL SETUP
------------

Step 1: Install LLVM/Clang (Required for Whisper)
--------------------------------------------------
Option A - Using winget:
    winget install LLVM.LLVM

Option B - Manual download:
    https://github.com/llvm/llvm-project/releases
    Install to: C:\Program Files\LLVM

After installation:
    - Add to PATH: C:\Program Files\LLVM\bin
    - Restart terminal

Step 2: Download Whisper Model
-------------------------------
Create directory:
    mkdir models\whisper

Download model:
    https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin

Place in:
    models\whisper\ggml-base.bin

Model options:
    - ggml-tiny.bin    (75 MB)  - Fastest, lower accuracy
    - ggml-base.bin    (142 MB) - Balanced (RECOMMENDED)
    - ggml-small.bin   (466 MB) - Better accuracy
    - ggml-medium.bin  (1.5 GB) - High accuracy

Step 3: Build with Whisper
---------------------------
    cargo build --release --bin agent_guru_voice --features whisper

Step 4: Run
-----------
    target\release\agent_guru_voice.exe

FALLBACK MODE (No Whisper)
---------------------------
If you don't want to install LLVM or download models:

Build without Whisper:
    cargo build --release --bin agent_guru_voice

This uses enhanced audio analysis for development/testing.

CONFIGURATION
-------------
Edit .kiro/llm_config.yaml to configure:

voice:
  stt:
    engine: whisper
    model_path: "./models/whisper/ggml-base.bin"
    language: "en"
    n_threads: 4

TROUBLESHOOTING
---------------

Error: "Unable to find libclang"
Solution: Install LLVM and add to PATH

Error: "Whisper model not found"
Solution: Download model to models\whisper\ggml-base.bin

Error: Build takes too long
Solution: Use ggml-tiny.bin or ggml-base.bin instead of larger models

PERFORMANCE
-----------
Expected latency with ggml-base.bin:
- Wake detection: <50ms
- Speech-to-text: <120ms (target met)
- Total pipeline: <500ms

VERIFICATION
------------
After setup, test the system:

1. Run: target\release\agent_guru_voice.exe
2. Say: "Guru" or "Maya" (wake word)
3. Speak your command
4. Verify transcription appears
5. Hear AI response
