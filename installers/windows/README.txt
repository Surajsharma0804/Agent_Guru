Agent Guru - Voice-Driven AI Companion
========================================

Installation Instructions:

1. Run setup.bat to configure Agent Guru
2. Follow the on-screen instructions
3. Start Agent Guru by running: bin\agent_guru_voice.exe

Voice Commands:
- Say "Hey Guru" or "Hey Maya" to wake up
- Speak naturally to interact
- Say "Stop listening" to pause
- Say "Exit" or "Goodbye" to quit

Configuration:
- Config file: config\llm_config.yaml
- Logs: %USERPROFILE%\.kiro\logs\
