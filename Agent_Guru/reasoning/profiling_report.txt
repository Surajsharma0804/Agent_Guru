================================================================================
COMMON BOTTLENECKS TO LOOK FOR
================================================================================

Serialization:
  - json.dumps, pickle.dumps in flame graph
  - Solution: Use orjson (5-10x faster)

Database Queries:
  - execute, fetchall in flame graph
  - Solution: Connection pooling, batch queries

Regex Compilation:
  - re.compile, re.match in flame graph
  - Solution: Pre-compile patterns at module level

LLM API Calls:
  - requests.post, httpx.post in flame graph
  - Solution: Async HTTP, connection pooling, prompt caching

Memory Allocation:
  - list.append, dict.__setitem__ in flame graph
  - Solution: Pre-allocate buffers, use generators
