## Pipeline Control

| Command | Effect |
|---------|--------|
| "Stop listening" / "Pause" | Pause voice detection |
| "Hey Guru" / "Hey Maya" | Resume from pause |
| "Exit" / "Goodbye" / "Quit" | Shut down Agent Guru |
