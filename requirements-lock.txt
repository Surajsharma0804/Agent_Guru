# NOT with:          pip freeze > requirements-lock.txt
# PowerShell's `>` writes UTF-16LE. This file was UTF-16LE, which pip and
# uv only read because they sniff the BOM -- most other tooling, and every
# line-based diff, sees it as binary. It is UTF-8 now; keep it that way.
#
# Removed: -e git+https://github.com/Surajsharma0804/Agent_Guru.git@63de14801e9c1f2df4ee90be75dcf699b9172ce2#egg=agent_guru
#   A lock file that installs the project itself from a pinned GitHub
#   commit made `pip install -r requirements-lock.txt` clone the repo over
#   the checkout being built, and fail outright without credentials.
#

#   aioredis 2.0.1 raises TypeError: duplicate base class TimeoutError on
#   import under Python >= 3.11, this project's declared minimum. See the

#   been accepted as unreachable; upgrading removes the need to be right about
