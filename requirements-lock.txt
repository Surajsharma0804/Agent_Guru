# NOT with:          pip freeze > requirements-lock.txt
# PowerShell's `>` writes UTF-16LE. This file was UTF-16LE, which pip and
# uv only read because they sniff the BOM -- most other tooling, and every
# line-based diff, sees it as binary. It is UTF-8 now; keep it that way.

#   the checkout being built, and fail outright without credentials.

#   installing the file brought back js2py (no fixed release for its
#   advisories) and beautifulsoup4 unpinned. pip now resolves every pin
#   here to exactly the pinned version and installs nothing else.
